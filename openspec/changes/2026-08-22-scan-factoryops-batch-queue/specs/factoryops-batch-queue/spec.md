# FactoryOps Batch Queue 规格

## 新增需求

### Requirement: 根目录的直接子目录形成独立批次

系统必须仅在操作者明确选择根目录后扫描其直接子目录。每个至少包含一张受支持图片的直接子目录形成一个批次；批次 ID 使用相对目录名的安全规范化结果，并保留原始显示名称。根目录中的散落图片、嵌套二级目录、空目录和不支持的文件必须被忽略并在扫描摘要中说明，不得静默并入其他批次。

#### Scenario: 扫描多个批次

- **Given** 根目录包含 `batch-001`、`batch-002` 和 `notes.txt`
- **And** 两个批次目录分别包含有效图片
- **When** 操作者扫描根目录
- **Then** 队列包含两个独立批次
- **And** `notes.txt` 不形成批次且扫描摘要说明其被忽略

### Requirement: 扫描必须冻结可验证的输入清单

每个入队批次必须保存图片相对路径、文件大小和 SHA-256 内容摘要形成的有序清单摘要。相同根目录重复扫描时，相同批次 ID 与相同清单不得创建第二个活动队列项；相同批次 ID 但清单变化必须显示为“内容已变化”，由操作者明确重新检测，不得覆盖历史 Run。

#### Scenario: 重复扫描未变化批次

- **Given** `batch-001` 已经入队且图片清单未变化
- **When** 再次扫描同一根目录
- **Then** 系统复用现有队列身份
- **And** 不启动新的模型调用或覆盖历史结果

### Requirement: 队列必须连续且隔离地执行批次 Run

系统必须为每个批次创建独立 Run，并按可配置但有上限的并发度派发；首版默认并发度为 1。批次进入待审批、失败、取消或等待复检时，队列仍须继续派发后续批次。暂停只停止新批次派发，不中断已经运行的批次；继续后恢复派发。

#### Scenario: 待审批批次不阻塞后续批次

- **Given** `batch-001` 完成后进入待审批
- **And** `batch-002` 正在等待
- **When** 队列调度下一项
- **Then** `batch-002` 获得自己的 Run 并开始检测
- **And** `batch-001` 保持待审批且历史证据不变

### Requirement: 结论必须由结构化证据和确定性策略路由

系统必须先获得批次级 Coordinator 结论和 Risk / Policy 结构化结论，再由非 LLM 的确定性路由器选择终态。无异常且无风险动作的批次标记为 `QA_ACCEPTED`；证据不足或明确建议复检的批次标记为 `RECHECK_REQUIRED`；需要人工批准的动作标记为 `WAITING_FOR_APPROVAL`；不可解析或相互矛盾的输出必须失败关闭，不能自动通过。

#### Scenario: 正常批次自动质检通过

- **Given** 所有图片检查完成且批次结论无异常
- **And** Risk / Policy 不要求动作或审批
- **When** 确定性路由器评估结果
- **Then** 队列项标记为 `QA_ACCEPTED`
- **And** 不调用业务 Batch release 或 hold API

#### Scenario: 高风险动作进入待审批

- **Given** Risk / Policy 提议 `STOP_LINE` 并要求人工审批
- **When** 确定性路由器评估结果
- **Then** 队列项标记为 `WAITING_FOR_APPROVAL`
- **And** 保存动作、风险等级、策略引用和证据摘要
- **And** 不执行生产线动作

### Requirement: 队列操作和历史必须可恢复

队列项、输入清单、Run 关联、状态迁移和路由结果必须持久化。页面刷新或服务重启后必须恢复队列状态。重试失败批次必须创建可区分的派生 Run 并引用原 Run；取消待运行项不得产生模型调用；历史查看不得调用模型。

#### Scenario: 服务重启后恢复队列

- **Given** 一个批次正在等待、另一个批次已经质检通过
- **When** 服务重启并重新打开工作台
- **Then** 两个批次及其状态恢复
- **And** 已完成批次的历史查看不产生新 Run

### Requirement: Kafka 状态必须如实展示

本地目录队列通过 HTTP 创建 Run 时必须标记 `transport.mode=http-local` 与 `kafka_used=false`。只有具有真实 topic、partition 和 offset 证据的 Run 才能显示为 Kafka 触发。队列界面不得暗示 Agent 间通过 Kafka 聊天。
