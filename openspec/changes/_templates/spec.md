# <Capability> 规格增量

## 新增需求

### Requirement: <可验证的能力名称>

系统必须满足的明确行为。使用“必须”表达强制要求，避免无法测试的模糊描述。

#### Scenario: <场景名称>

- **Given** 明确的初始状态
- **When** 明确的事件或操作
- **Then** 可观察、可验证的结果
- **And** 必要的附加约束

## 修改需求

仅在修改已经生效的 `openspec/specs/` 需求时保留本节，并完整写出修改后的 Requirement 与 Scenario。

## 移除需求

仅在移除已经生效的需求时保留本节，并说明移除理由、兼容影响和迁移方式。
